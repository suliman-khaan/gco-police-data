# GCO Police Data

WordPress plugin for Gun Cabinets Online that stores police force FOI responses and NPCC
firearms-licensing figures, and renders the police licensing portal and force pages from them.

- Requires: WordPress 6.5+ (tested on 7.1), PHP 8.1+
- License: proprietary — built for guncabinetsonline.co.uk

Installation, shortcodes and admin usage will be documented here as the plugin is built.
